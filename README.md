### 🧩 Combine Widgets Creatively
Don't be afraid to mix different types of widgets. A clock widget next to a weather widget, combined with a note widget, creates a powerful information dashboard at a glance.

### ⚡ Optimize Performance
While docstudio is lightweight, having many live widgets with frequent updates can use more system resources. If you notice performance slowdowns, try:
- Reducing the number of live widgets
- Increasing refresh intervals for less critical widgets
- Using static widgets instead of live ones for non-essential information



### 🎨 Personalize with Themes
Take advantage of the theming system to match your widgets to your desktop wallpaper or personal style. You can create custom color schemes show give your desktop a cohesive, polished look.



## 🔧 TroubleshootingCommon Issues

### 🚫 Widgets Not Appearing on Desktop
If you've applied a layout but don't see widgets on your desktop:
- Check that docstudio is still running in the background
- Ensure widgets aren't hidden behind other windows (try clicking the docstudio icon in the menu bar)
- Verify your layout is set to "Enabled" in the layout manager



### 🌡️ Weather Widget Showing Incorrect Location
Make sure you've entered the correct city or region in the weather widget settings. Weather data updates periodically, so allow a few minutes for changes to take effect.



### ⚙️ Widgets Not Updating in Real-Time
Check the refresh interval setting for your widget. If you've set a long interval (like 30 minutes),) updates will be infrequent. Set a shorter interval for more frequent updates, keeping in mind that more frequent updates use more system resources.



### 🔄 Can't Drag Widgets
Make sure you're clicking directly on the widget body and not on any interactive elements (like buttons or links within the widget). If issues persist, try restarting docstudio.
